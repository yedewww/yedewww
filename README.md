## 🛠️ What I work on

- 🤖 **Agents**: multi-agent and multi-step workflows with LangGraph and MCP
- 🔍 **Retrieval and knowledge**: agentic RAG, multimodal RAG, GraphRAG
- 📊 **Evaluation and reliability**: LLM evaluation, observability, structured outputs, prompt caching
- ☁️ **Production engineering**: cloud-native microservices on Azure, Docker, Kubernetes, CI/CD

Before LLMs I worked in classical machine learning and deep learning, mainly NLP, computer vision, and anomaly detection. Some of the older repositories here are from that time.
